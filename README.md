Vintage Story doesn't have much in the way of passive base defense, so I set out to rectify that with some simple crude additions available from day 1.

Thanks to Thalius for the new art and ideas, I was finally able to get off my butt and create the walls how I originally envisioned them. They can now be modularly stacked to a configurable maximum height.

Need support? Check out my discord: https://discord.gg/yJdawheDCS

# Defenses
- Sharpened wooden stakes (Archer's Stakes)
    - Crafted with 4 firewood
    - Has 25 hit points before it self destructs
    - Deals 2 damage
- Embedded copper spears (Archer's Copper Spears)
    - Crafted with Archer's Stakes and a single copper spearhead
    - Has a longer lasting 60 hit points
    - Deals 3 damage
- Spiked Barricade
    - Crafted with 5 firewood in an X shape
    - Larger more durable version of the stakes
    - Will only damage entities walking over them

# Walls
- Palisade Walls
    - Crafted with 3 logs and an axe
    - Can be stacked up to a configurable 6 blocks
- Palisade Corners
    - Crafted with 4 logs and an axe
    - Can be stacked up to a configurable 6 blocks
    - Great for filling in corners
- Palisade Walkway
    - Crafted with 2 palisade walls
    - Can be attached to palisade walls to create walkways
- New models: Thalius

# Known Issues:

- Stability will allow floating structures if they are "supporting eachother". Unsure if this is worth fixing.
